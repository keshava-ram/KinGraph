Graph Theory vs. Naive Trees

Why Kinship Requires Directed Graphs

Traditional binary or n-ary trees break when confronted with real-world genealogy.

Dual-Parent Convergence

Every person has two biological parents. In strict trees, nodes can have only one parent. KinGraph models this accurately as a Directed Acyclic Graph (DAG) with convergent in-degree edges.

Cycle Detection & Paradox Prevention

Biological ancestry is strictly chronological. KinGraph uses iterative DFS cycle checks to mathematically prohibit paradoxical relationships where a descendant is declared an ancestor of their progenitor.

Orthogonal Spouse Modeling

Marriage is a bidirectional partnership, not an ancestral lineage. KinGraph decouples spouse adjacency lists from parent-child directed edges, ensuring clean generation alignment.

G

1. Graph with Adjacency Lists

Definition: GraphVertex represents vertices; directed Edge structs represent parent-to-child links. Spouses are tracked in a dedicated adjacency list.

  • Single Instance: Each person is allocated exactly once in heap memory.
  • Bidirectional Reachability: Each vertex maintains outgoing children and incoming parents for $O(\text{deg})$ parent/child lookups.
  • Memory Complexity: $O(V + E)$ where $V = \text{people}, E = \text{relationships}$.
H

2. Hash Table with Separate Chaining

Definition: Fixed-size bucket array with linked list chaining to resolve collisions on string IDs (e.g. P01, P02).

  • Hash Function: DJB2 algorithm: hash = ((hash << 5) + hash) + c.
  • Time Complexity: $O(1)$ average case for lookup, insertion, and deletion.
  • Consistency: When a vertex is removed, it is cleanly extracted from the collision chain.
Q

3. Dynamic FIFO Queue & BFS

Definition: Pointer-based FIFO queue with $O(1)$ enqueue and dequeue operations.

  • Generation Leveling: Roots are identified ($\text{in\_degree} = 0$), enqueued at level 1, and children assigned $\text{gen} + 1$ level by level.
  • Shortest Path: Finds the minimum unweighted degree of separation between any two individuals in $O(V + E)$.
S

4. Dynamic LIFO Stack & Iterative DFS

Definition: Pointer-based LIFO stack with $O(1)$ push and pop operations.

  • Iterative Ancestry: Climbs parent pointers without risking recursion call-stack overflow on deep lineages.
  • Cycle Detection: Verifies that a target child cannot reach the candidate parent before creating a directed edge.
